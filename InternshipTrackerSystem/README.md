# InternshipTrackerSystem
1. Download the SQL script file first.
2. Save it locally in SSMS and name it InternshipTracker, confirm the Server as localhost.
3. Open script in SSMS and F5(run)
4. Open Visual Studio → File → Clone Repository
5. Paste your GitHub repo link, choose a local folder → click Clone

For every time you edit the code(Visual Studio) or GitHub file, you must commit and then push.
